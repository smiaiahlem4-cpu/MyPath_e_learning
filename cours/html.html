Cours HTML : les bases du langage

Un cours écrit pour apprendre à structurer une page web.

Objectifs pédagogiques

  • Comprendre le rôle de HTML dans une page web.
  • Écrire la structure de base d'un document HTML5.
  • Utiliser les balises sémantiques.
  • Ajouter des titres, des liens, des images et des listes.

1. Qu'est-ce que HTML ?

HTML (HyperText Markup Language) est le langage qui décrit la structure et le contenu d'une page web. Le navigateur lit les balises et affiche le résultat : titres, paragraphes, images, formulaires, etc.

HTML s'occupe du contenu. L'apparence est gérée par CSS et le comportement par JavaScript.

2. Structure d'une page

Tout document HTML5 suit le même squelette :

<!DOCTYPE html>
<html lang="fr">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Ma première page</title>
</head>
<body>
  <h1>Bonjour</h1>
  <p>Ceci est mon premier paragraphe.</p>
</body>
</html>

2.1 Le head et le body

Le head contient les informations invisibles (titre de l'onglet, encodage, feuilles de style). Le body contient tout ce qui s'affiche à l'écran.

2.2 Les balises sémantiques

Elles donnent du sens à chaque zone de la page, ce qui aide l'accessibilité et le référencement :

  • header : l'en-tête de la page ou d'une section.
  • nav : un menu de navigation.
  • main : le contenu principal (un seul par page).
  • article et section : des blocs de contenu.
  • aside et footer : contenu secondaire et pied de page.

3. Texte, liens, images et listes

<h2>Mes cours</h2>
<p>Voici la liste de mes cours :</p>
<ul>
  <li><a href="css.html">Cours CSS</a></li>
  <li><a href="javascript.html">Cours JavaScript</a></li>
</ul>
<img src="logo.png" alt="Logo du site">

Pensez toujours à renseigner l'attribut alt des images : il décrit l'image aux personnes qui ne peuvent pas la voir.

Résumé

  • HTML décrit la structure et le contenu d'une page.
  • Un document commence par <!DOCTYPE html> puis html, head et body.
  • Les balises sémantiques (header, nav, main, footer…) rendent la page plus claire.
  • Les images doivent toujours avoir un attribut alt.
